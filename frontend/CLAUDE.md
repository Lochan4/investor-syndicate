# QCI Club — Design Rules

## Brand direction
- Audience: investors and founders. Tone: credible, calm, premium. Not "startup neon."
- One typeface pair, max 2 weights each. One accent color. Generous whitespace.
- No generic AI tropes: no purple gradients, no emoji icons, no centered-everything hero,
  no 3-card feature grids by default.

## Design loop (mandatory for every UI change)
1. Build the section.
2. Run the dev server and screenshot it with Playwright at 375px, 768px, and 1440px.
3. Critique the screenshots against the frontend-design and design-taste-frontend skills:
   hierarchy, spacing rhythm (8px scale), type scale, alignment, contrast, mobile overflow.
4. List the 3 worst issues, fix them, and re-screenshot.
5. Repeat until there are no major issues (max 3 rounds), then show me the final screenshots.
