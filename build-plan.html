Day 4
GraphRAG Engine + Conversation
↳ Investor can have a real AI conversation
The core AI: BFS traversal over pgvector, SSE streaming to the browser, Redis context store for upstream cell injection. CellChat component wired to real backend.
Backend
GraphRAG BFS traversal services/traversal.py
Step 1: pgvector ANN seed search (top-5 chunks by cosine sim)
Step 2: BFS expand via chunk_edges NEXT/SIMILAR_TO + chunk_mentions
Step 3: Relevance = cosine_sim × 0.85^depth — threshold 0.45, cap 40 nodes
Step 4: Inject upstream cell_analysis from Redis (if downstream cell)
Step 5: Claude Opus streams answer over top-12 chunks as context
SSE stream endpoint GET /conversation/{id}/stream
Events: answer_token {token} → answer_done {sources: [asset_ids]}
No node_visited events exposed to frontend
Redis cell context store services/cell_context.py
RPUSH cell_ctx:{pid}:{cid}:{uid} per turn — TTL 30 days
GET cell_analysis:{pid}:{cid} → inject into downstream prompts
Conversation endpoints
POST /projects/{id}/sessions/{cellId} — create/get session
POST /conversation/{id}/message — save + run traversal
POST /conversation/{id}/submit — mark submitted + maybe_close

Tech Stack
Layer Choice Why
Frontend Next.js 14 App Router + Tailwind + shadcn/ui Server components for data fetching, nested layouts for auth guards, App Router for parallel route loading
Auth WorkOS AuthKit Hosted auth UI, MFA, invite emails — eliminates auth code entirely (3 files). Free up to 1M MAU.
Backend API FastAPI + Pydantic + asyncpg Async-first, native SSE support, Pydantic validates every LLM JSON output, asyncpg for non-blocking DB queries
Database Supabase Postgres + pgvector (HNSW) pgvector replaces Neo4j — same GraphRAG algorithm, zero extra service, project isolation enforced by FK at the schema level
Job Queue Arq + Upstash Redis Async-native Python worker queue, idempotent job keys, progress reporting via Redis TTL keys, 180s timeout for LLM calls
LLM Claude API — Opus 4.6 / Sonnet 4.6 Opus for deep analysis (consensus, final report, chat). Sonnet for extraction tasks (NER, competitive assessment, cell synthesis, vision).
Embeddings OpenAI text-embedding-3-large 1536-dim vectors, best semantic similarity for financial/startup content. Works natively with pgvector HNSW cosine index.
Flow Canvas React Flow Custom cell + satellite nodes, admin drag-connect, investor read-only pan/zoom — all in one library with a stable API
Storage Cloudflare R2 Zero egress cost (unlike S3), S3-compatible presigned URL API, handles all raw asset files. Free for MVP-scale volume.
Email Resend Simple REST API, React Email template support. Only used for analysis-ready notifications — invites are handled by WorkOS.
